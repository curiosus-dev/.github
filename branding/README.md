# Curiosus branding

| File | Use |
|---|---|
| `curiosus-logo.svg` | Source, any size |
| `curiosus-logo-128.png` | NuGet package icon (synced to the libraries as `build/curiosus-icon.png` by [dotnet-tools](https://github.com/curiosus-dev/dotnet-tools)) |
| `curiosus-logo-512.png` | README headers, docs site logo, social previews |
| `curiosus-logo-1024.png` | High-resolution displays, organization avatar |

Link from READMEs and docs by the raw URL, e.g.

```markdown
<img src="https://raw.githubusercontent.com/curiosus-dev/.github/main/branding/curiosus-logo-512.png" width="128" alt="Curiosus">
```
