# .github

Default community health files for the [curiosus-dev](https://github.com/curiosus-dev) organization. GitHub uses them
in every public repository that doesn't have its own:

- [`SECURITY.md`](SECURITY.md), [`CONTRIBUTING.md`](CONTRIBUTING.md)
- [issue templates](.github/ISSUE_TEMPLATE) and the [pull request template](.github/pull_request_template.md)
- [`profile/README.md`](profile/README.md) — the organization profile page

Repository settings and shared build files live in [curiosus-dev/dotnet-tools](https://github.com/curiosus-dev/dotnet-tools).
