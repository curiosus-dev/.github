# Curiosus

Open-source .NET libraries, published on [nuget.org](https://www.nuget.org/profiles/curiosus-dev).

| Library | Packages | |
|---|---|---|
| [Curiosus.Migrations](https://github.com/curiosus-dev/Curiosus.Migrations) | `Curiosus.Migrations`, `.PostgreSQL`, `.SqlServer`, `.Utils` | Database migrations with SQL scripts and C# code: downgrades, long-running migrations, policies |
| [Curiosus.Utils](https://github.com/curiosus-dev/Curiosus.Utils) | `Curiosus.*` (37 packages) | Building blocks for .NET services: configuration, hosting, data access, email and SMS, notifications, request processing |
| [Curiosus.TelegramBot](https://github.com/curiosus-dev/Curiosus.TelegramBot) | `Curiosus.TelegramBot` | Infrastructure for Telegram bots: command dispatching, multi-step state, persistent update queue |

Formerly published as `Curiosity.*` by SIIS Ltd and as `Markeli.TelegramBot`.

Maintained by [Maxim Markelow (@markeli)](https://github.com/markeli).
